\# 3D Tactical Shooter



A collaborative 3D tactical shooting game developed for the

SE3032 Graphics and Visualization and SE3062 Intelligent Systems modules.



\## Project Overview



The project combines:



\- Interactive 3D environment design

\- Player interaction and physics

\- Custom 3D assets

\- Autonomous AI agents

\- Dynamic pathfinding and decision-making

\- Character movement and animation



\## Technology Stack



\- \*\*Game Engine:\*\* Unity 6.3 LTS

\- \*\*Programming Language:\*\* C#

\- \*\*3D Modelling:\*\* Blender

\- \*\*Version Control:\*\* Git \& GitHub

\- \*\*Target Platform:\*\* Windows



\## Team



Four team members are responsible for:



1\. World Builder

2\. Systems Engineer

3\. Core Developer

4\. Agent Controller



\## Repository Structure



The Unity project and supporting documentation will be organized

into a structured project architecture to support collaborative development.



\## Development Status



\*\*Current Phase:\*\* Project Configuration



The current work focuses on configuring the repository, Unity project,

development environment, and collaboration workflow before gameplay
